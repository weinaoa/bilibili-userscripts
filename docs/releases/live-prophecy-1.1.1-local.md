# 直播预言 1.1.1：复用原生悬停弹层

此版本按直播页原生“弹幕设置 / 弹幕屏蔽 / 特效屏蔽”的方式展开预言，并修正默认弹出位置。

安装：用本地 `bilibili-live-prophecy.user.js` 全文替换 Tampermonkey 中已有脚本并保存，刷新整个直播间，悬停图标确认显示 `v1.1.1`。仅启用一份预言脚本；本地改版没有发布到远程。

- **悬停与关闭**：直接接入现有聊天 Vue VM 的 `setting-dialog`，调用原生 `toggleDialog`、`closeDialog`、`clearCloseTimer` 和 `mouseClose`。未另写悬停定时器，未改写原生方法和渲染函数。指针点击不会把刚悬停打开的面板立即关掉；键盘、Shift+点击和油猴菜单保留。
- **弹出位置**：使用原生 `top-left` 弹层的真实矩形，默认在弹幕工具栏上方，宽度随弹幕区（最大 420px），高度最多 600px 并受上方空间限制。监听视口/滚动/原生动画完成，跟随原生锚点更新。
- **旧位置**：更换位置缓存键，重置 1.1.0 的右上角坐标。用户主动拖动后才进入自由放置模式，保持手动关闭及会话位置保存。
- **组件保留**：原生弹层只提供生命周期和定位参照，实际 iframe 始终留在原来的持久宿主内。原生弹层的 `v-if` 或离场动画不会销毁 iframe；透明参照外壳不会覆盖其他原生设置。切换到原生设置时关闭预言并取消未确认的选择。
- **输入与确认**：悬停不抢走弹幕输入焦点；鼠标可从图标移入面板和 iframe。确认期间的偶然移出不会取消选择；关闭按钮、切房和主动切换其他原生设置仍会取消未确认的选择。

页面尚无原生聊天 Vue 控制器时，点击和菜单入口继续可用，位置优先贴合已存在的弹幕区。原生控制器加载或重建后自动接入，不复制原生代码或修改账号鉴权。

- 原生组件联网联测通过：从官方公开资源加载真正的 `SettingDialog` 和聊天控制方法，在受控宿主内实例化；验证悬停展开、原生 200ms 关闭的取消、面板/iframe 移入、确认期间移出、原生设置切换和 iframe 实例复用。320px 弹幕区内面板宽度为 320px，底部与工具栏上缘对齐，没有进入旁边播放器区域。原生业务 API 均被拦截；导入原生模块产生的后台网络错误单独记录，用户脚本来源没有运行错误。
