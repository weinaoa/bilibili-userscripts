# 直播预言 1.1.3：解除弹幕区裁剪

1.1.2 将宽面板放在弹幕定位容器内，遗漏了祖先容器的 `overflow` / 绘制裁剪。尺寸和坐标正确不代表内容实际可见，本次加入与用户截图对应的可见性回归。

安装：将本地 `bilibili-live-prophecy.user.js` 全文替换到 Tampermonkey，保存后刷新整个直播间。版本为 `v1.1.3`，本地版本未发布远程。

## 修改

- 420px 面板的持久宿主移到文档根显示层，通过浏览器原生 `popover="manual"` 顶层显示，避开弹幕区的 `overflow:hidden`、`contain:paint`、圆角及祖先变换裁剪。
- 仍调用直播页原生 `setting-dialog` 的悬停、关闭和延迟取消方法，没有另写悬停定时器。锚点仍取自弹幕工具栏，保持右边缘对齐弹幕区、底部贴在工具栏上方。
- 只读取稳定工具栏矩形，分别处理锚点和顶层宿主的 CSS 缩放，不读取原生弹层动画矩形，也不回写原生 Vue 尺寸。
- 打开、关闭、刷新布局及全屏时均不搬动 iframe；关闭重开保留同一实例。拖动保持原面板尺寸，工具栏重建后更新锚点引用。
- 已隐藏面板的鼠标移出不会再次调用原生关闭，避免重复关闭干扰随后打开的设置。
- 保留 1.1.2 的反馈文字单行、选项等高和跨脚本环境的 iframe 标识。

## 复现与验证

测试宿主为 320px 宽弹幕侧栏，增加 `overflow:hidden` 和 `contain:paint`。旧版仍能通过矩形尺寸和坐标断言，但标题、页脚的左边缘点击检测失败，复现“左侧被截断”。

新版原生组件测试在正常、1.25 倍 CSS 缩放、1.5 倍 CSS 缩放、缩放叠加祖先 transform 四种场景检查：

- 面板实际右缘/底缘与工具栏锚点对齐。
- 使用 `elementFromPoint()` 检查标题和页脚四个边缘都属于面板，而不是裁剪后的播放器或页面背景。
- 在 iframe 左侧内容上发送真实浏览器鼠标操作，确认能选择、取消并正常切换原生设置。
- 60 帧内无面板/播放器跳动、重复显隐或空闲 DOM 改写。
- 关闭重开、进入/退出全屏保持同一 iframe。

官方 H5 联测也使用带圆角、溢出裁剪和绘制隔离的侧栏，核对完整标题/页脚的可点击性；模拟账号与数据，参与 POST 均被拦截。反馈文字在 420/360/320/280px 下保持一行，两侧短答案按钮均为 76px。

```powershell
npm run test:prophecy
npm run test:prophecy:browser
```
