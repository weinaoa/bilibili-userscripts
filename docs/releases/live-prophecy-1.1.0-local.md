# 直播预言 1.1.0：本地悬浮面板版

2026-11-01，在已克隆项目上修改 `bilibili-live-prophecy.user.js`。未提交、推送或发布远程版本。

## 安装与使用

1. 在 Tampermonkey 管理面板打开已有“B站直播预言”，用本地 `bilibili-live-prophecy.user.js` 的完整内容替换并保存；首次安装可新建脚本。只启用一份预言脚本。
2. 刷新整个直播间，悬停星芒图标确认显示 `v1.1.0`。点击打开，再次点击收起；Shift+点击打开参与历史。无工具栏时使用油猴菜单“打开直播预言”或“查看预言参与记录”。
3. 拖动标题栏调整位置，当前标签页会话内保留。关闭不会重建官方页面；刷新只重建 iframe，并保留当前预言、历史或规则路由。
4. 选择选项后，只有点击确认才继续官方流程。取消、确认时按 Escape、关闭面板或切房均不会确认未提交的选择。确认期间暂停切页和刷新；已确认并发出的请求不会因收起面板而撤销。
5. 正常操作留在面板内。底部“备用入口”仅供用户手动选择；官方登录可以打开必要的外部验证页面。官方 SDK 的外部帮助链接显示为明确标注新标签页的手动链接。

本地版本的 `@updateURL` 和 `@downloadURL` 均为 `none`，避免被上游独立窗口版本覆盖；`@downloadURL none` 的更新行为见 [Tampermonkey 文档](https://www.tampermonkey.net/documentation.php?q=update_url)。README 原来的远程安装链接仍指向上游，不会安装此本地改版。

## 实现与复用

采用 **同源 iframe + Shadow DOM 外壳**，没有重写官方竞猜卡片或参与规则。官方地址：

[Bilibili 官方预言 H5](https://live.bilibili.com/p/html/live-app-guessing-game/index.html)

- `openPrediction()` 默认控制面板显示状态；`officialUrl()` 保留主播 UID 和官方 hash 路由。新增面板生命周期、拖动、会话位置、视口约束、加载状态和手动备用入口。
- `createUI()` 保留弹幕工具栏图标、背景适配和 Shift 入口，增加面板展开状态。播放器、弹幕输入和页面滚动容器保持原节点。
- 复用原有 UID 识别、短房号解析、缓存、重试、断网恢复和晚返回请求校验。切房销毁旧 iframe，额外在确认和参与发送之前校验房间。
- `adaptOfficialDesktop()` 仍在官方文档运行。保留 `document-start`、覆盖 iframe 的 `@match`，未加 `@noframes`；父页面在同源 iframe 加载后补装并复用同一适配实例，兼容 SDK 已缓存的情况。
- 仅在官方 iframe 内为现有 API 模块的 `post()` 增加进行中参与请求去重及交互锁，返回原请求的结果或错误。`SDK.Request`、账号读取、资格/余额检查、请求参数、凭据和官方反馈逻辑不变；其他 POST 不受此包装影响。参与没有自动重试。
- 确认弹窗保留在 iframe 内，通过视口最大高度、内部滚动、取消优先焦点和 Tab 约束保证小窗口可操作。父面板关闭会调用取消；不会把关闭事件转成确认。
- 顶层 popover 用于在播放器全屏后继续显示面板，不移动 iframe，避免浏览上下文重建。原生视频全屏没有工具栏时，先打开面板或使用油猴菜单。
- iframe 使用常规 sandbox 权限，允许官方脚本、同源账号读取、表单和必要登录弹窗，不授予顶层导航权限。未修改响应头、关闭浏览器安全策略或绕过鉴权。

## 复现

Node.js 20+，安装测试依赖后运行；用户脚本自身没有新增运行时依赖：

```powershell
npm ci
npm run test:prophecy
npm run test:prophecy:browser
npm test
```

浏览器测试默认使用已安装的 Chrome。可通过 `BROWSER_PATH` 指向 Chrome/Chromium 可执行文件，例如 Edge；也可安装 Chromium 并设置该路径。浏览器检查不会关闭浏览器安全选项。离线集成测试拦截全部网络请求。

开发期还使用官方 H5 和模拟接口进行联网联测，不导入账号，拦截真实参与请求。发布前整理已移除这些联网探针，此处线上结论保留为当时的验证记录；当前可运行的命令见上方离线测试。

离线浏览器测试可将 `PROPHECY_SCREENSHOT_DIR` 设置为 `test-results/` 导出截图，不包含登录凭据，也不会导入个人浏览器资料。

## 限制与来源

官方页面和 SDK 属于外部依赖。当前适配继续依赖上游已使用的 Webpack SDK 模块 `1171`，新增请求防重适配依赖 API 模块 `6151`。官方修改模块或页面结构、响应头增加嵌入限制、或扩展禁用 iframe 脚本时，面板会在检查失败/20 秒超时后提示重试；不会自动改成新标签页。遇到此类变化需更新适配。

现代桌面 Chromium 的 popover/全屏已测；移动端、Safari、Firefox、第三方播放器全屏以及特殊扩展组合未测。活动页内的嵌套直播间只能在其自身文档视口内显示面板。极低高度下确认对话框需要内部滚动。
